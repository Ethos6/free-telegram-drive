Set up encryption

Every file is encrypted on this server before it goes to Telegram. The key is created once and shown to you as a recovery key.

Your recovery key

Write it down or store it in a password manager. Without it, nobody (not even you) can recover your files if this server is lost.

Restore with your recovery key

Next, link the same Telegram accounts and choose Rebuild from Telegram in Settings to bring back all folders and files.

Accounts

Add a Telegram account

Sign in with the phone number of any Telegram account. Files are stored, encrypted, in that account's Saved Messages, and big files are spread over all your accounts.

Demo: use phone +1 555 0100 and code 12345.

Telegram sign-in is not configured on this server yet. Set TELEGRAM_API_ID and TELEGRAM_API_HASH (see the README, section "Telegram setup"), then restart.

Telegram Drive signs in as a normal Telegram app (it appears under Settings → Devices). Your Telegram password is sent to Telegram only and is never stored.

Settings

Use it as a drive on your computer or phone (WebDAV)

Address:

Sign in with any user name and an app password from below. Windows: File Explorer → This PC → Map network drive. macOS: Finder → Go → Connect to Server. Linux: your file manager, with a davs:// address. iPhone and Android: any WebDAV file manager app, or add this web app to your home screen. Use an https address when connecting over the internet.

App passwords

    Encryption and backup

    Files and file names are encrypted with AES-256-GCM before they reach Telegram. An encrypted copy of the folder index is kept in Saved Messages so everything can be rebuilt on a new server.

    Share links

    Anyone with a link can download that file until the link expires.
